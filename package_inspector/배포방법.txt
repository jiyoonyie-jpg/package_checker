======================================================
  패키지 AI 검수 & 디자인 시스템 — 웹 배포 가이드
======================================================

팀원 누구나 링크 하나로 접속할 수 있는 웹 서비스로 배포하는 방법입니다.
비용: 무료 (Streamlit Community Cloud 기준)


──────────────────────────────────────────
STEP 1. GitHub 계정 만들기
──────────────────────────────────────────
1. github.com 접속 → Sign up
2. 무료 계정 생성


──────────────────────────────────────────
STEP 2. 이 폴더를 GitHub에 올리기
──────────────────────────────────────────
방법 A (쉬운 방법 - 웹에서 직접)
  1. github.com/new 접속
  2. Repository name: package-inspector 입력
  3. Public 선택 → Create repository
  4. "uploading an existing file" 클릭
  5. package_inspector 폴더 안의 파일을 모두 드래그 앤 드롭
     (폴더 구조 그대로: utils/, data/, .streamlit/, app.py, requirements.txt)
  6. Commit changes 클릭

방법 B (GitHub Desktop 앱 사용)
  1. desktop.github.com 에서 GitHub Desktop 설치
  2. File → Add Local Repository → package_inspector 폴더 선택
  3. Publish repository 클릭


──────────────────────────────────────────
STEP 3. Streamlit Community Cloud 배포
──────────────────────────────────────────
1. share.streamlit.io 접속
2. GitHub 계정으로 로그인
3. "New app" 클릭
4. Repository: package-inspector 선택
5. Main file path: app.py 입력
6. Advanced settings → Secrets 탭에서 아래 입력:

   GEMINI_API_KEY = "여기에_Gemini_API_키_입력"

7. Deploy! 클릭
8. 1~2분 후 링크 생성 완료!
   예) https://팀이름-package-inspector.streamlit.app


──────────────────────────────────────────
STEP 4. 팀원과 공유
──────────────────────────────────────────
생성된 링크를 카카오톡/슬랙/이메일로 공유하면 끝!
팀원은 설치 없이 브라우저에서 바로 사용 가능합니다.


──────────────────────────────────────────
Gemini API 키 발급 방법
──────────────────────────────────────────
1. aistudio.google.com 접속
2. Google 계정으로 로그인
3. 상단 "Get API key" 클릭
4. "Create API key" 클릭
5. 키 복사 후 Streamlit Secrets에 붙여넣기

★ Gemini API 무료 티어: 분당 15회 요청 (팀 내 테스트 충분)
   더 많이 쓰려면 유료 플랜 업그레이드 (사용량만큼 과금)


──────────────────────────────────────────
자주 묻는 질문
──────────────────────────────────────────
Q: 파일이 외부에 저장되나요?
A: 아니요. 분석은 Gemini API로 전송 후 즉시 처리되며 저장되지 않습니다.

Q: 팀원이 API 키를 알아야 하나요?
A: 아니요. Streamlit Secrets에 저장해두면 팀원은 키 없이 사용합니다.

Q: 무료로 얼마나 쓸 수 있나요?
A: Gemini Flash 기준 하루 수백~수천 회 분석 가능 (무료 티어).

Q: 이미지 생성(Imagen)이 안 되면?
A: Imagen은 Google AI Studio에서 별도 승인이 필요할 수 있습니다.
   aistudio.google.com에서 Imagen 사용 가능 여부를 확인하세요.
